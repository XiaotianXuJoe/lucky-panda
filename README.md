# 幸运熊猫（ADHD 训练版）

面向 ADHD 儿童的定时注意力训练系统。仿照服务器上的「方块对照」项目实现，零依赖 Node 服务 + 网页端游戏 + 家长邮件提醒。

## 训练流程（总时长约 21 分钟）

```
开场动画 40s           森林水晶被巫师偷走，森林变黑白
  ↓
第 1 阶段 · 跳跃水晶 6min
  ↓
转场动画 55s           累计拿到 X 颗水晶，前往山洞
  ↓
第 2 阶段 · 记忆翻牌 6min
  ↓
转场动画 55s           累计拿到 X 颗水晶，前往花丛
  ↓
第 3 阶段 · 推箱子 6min
  ↓
结束动画 40s           打败巫师，森林恢复色彩 → 谢谢参与
```

- **动画期间计时器暂停**，记入 `Time.rests`
- 每段游戏满 6 分钟自动切下一段，记入 `Training.block1/2/3Seconds`
- **切后台不算训练时间**，记入 `Time.pauses` 并暂停计时
- 计时基于真实时钟，不受浏览器后台标签页节流影响

## 三个小游戏（玩法严格对齐原小程序源码）

| 阶段 | 游戏 | 玩法 | 关卡 |
|---|---|---|---|
| 1 | 跳跃水晶 | **不同颜色的矩形板子从上往下落**，点屏幕左/右控制水晶的**跳跃方向**，引导它**穿过相同颜色的板子**、避开其他颜色；穿过同色后水晶会改变颜色；每 5 秒新出一排板子；穿对 **15** 次过关 | 5 关，板子格数 2→6 |
| 2 | 记忆翻牌 | 卡片先**全部亮出 10 秒**，随后统一翻面，凭记忆翻出两张相同信息；翻错 500ms 后自动盖回 | 5 关，牌数 4/8/12/16/20 |
| 3 | 推箱子 | 方向键 / W A S D 移动熊猫，把所有箱子推到圆圈上；步数统计 + 最佳步数（22/16/23/18/17），可按「重来」 | 5 关，原版 7×8 地图原样照抄 |

失败反馈已弱化（Q9）：穿错颜色 / 掉出底部只提示「再找一找～」，不扣分、不打断；推箱子可随时重来。

**阶段结束条件**：本阶段累计游戏满 **6 分钟**，**或**本阶段 **5 关全部通过** —— 先到者生效，随后播转场故事动画并进入下一阶段（不会绕回第 1 关，顶部水晶进度条单调递增）。

## 水晶激励

3 阶段 × 5 关 = **15 颗**。每通过一关的一级 +1 颗，显示在屏幕顶部。**不设保底**：未通过不加，同一关重复通过只计一次。

## 陪伴与讲解

- **熊猫陪伴**：右下角小熊猫，**每过 20 秒**按真实世界时间随机做伸懒腰 / 打哈欠 / 眨眼 / 招手 / 点头，与玩家表现无关
- **语音讲解**：每个阶段第一关前自动播放（浏览器 TTS 中文语音 + 文字规则），可点击「开始游戏」跳过

## 数据记录

每次会话上报一份结构化日志（服务端按 `sha1(编号|sessionStart)` 幂等 upsert）：

```json
{
  "Time":     { "sessionStart", "sessionEnd", "rests": [...], "pauses": [...] },
  "Training": { "block1Seconds", "block2Seconds", "block3Seconds" },
  "State":    { "maxStage": 3, "maxLevel": 5, "stages": {...} },
  "Crystal":  { "total": 12, "byStage": [5, 5, 2] },
  "Levels":   [ { "stage", "level", "passed", "seconds" } ],
  "Story":    [ { "kind", "watched", "skipped" } ]
}
```

对应三项需求：Time（开始/暂停/结束时间）、State（第几阶段第几级）、Training（三段各自时长）。

## 家长提醒

- **触发**：连续 3 天（72 小时）以上未参与或未完成训练
- **通道**：邮件（零依赖 SMTP-over-TLS，QQ 邮箱，无需 nodemailer）
- **自动窗口**：北京时间 09:00–09:29，每天至多一次
- **幂等**：内存标记 + `data.json` 落盘双保险，且先落盘再发送；进程重启当天也不重发
- **频控**：1 秒一封；仅发送成功才更新 `lastReminderAt`
- 后台「提醒」页可手动立即发送

邮件正文：

## 部署

```bash
# 服务器路径
/home/ubuntu/lucky-panda/
  ├── server.js            零依赖 Node HTTP 服务
  ├── data.json            全量数据（原子写入）
  ├── email-config.json    发件邮箱配置（权限 600，静态路径不可访问）
  ├── public/              静态资源（index.html / admin.html / play/）
  └── server.log

# 服务管理
sudo systemctl status  lucky-panda
sudo systemctl restart lucky-panda
sudo journalctl -u lucky-panda -f
```

- 端口 **8200**（8100 已被方块对照占用），systemd 守护，开机自启
- IP + 端口直连，无需域名与 ICP 备案
